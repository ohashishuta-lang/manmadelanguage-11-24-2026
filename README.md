# Conlang Studio

ドイツ語寄りの音韻体系を持つ独立した人工言語の学習・開発環境。

## v0.1

- 70語の暫定辞書、6レッスン
- 単語カード、リスニング、練習問題、簡易翻訳、学習記録
- 音声はドイツ語系合成音声による近似

## 利用方法

`index.html` をブラウザで開く。インストール不要。辞書・音声はHTMLに内蔵。学習記録はブラウザ内に保存され、端末間で自動同期されない。

## GitHub Pages

リポジトリの Settings → Pages → Build and deployment で Deploy from a branch を選択し、main / (root) を保存する。利用可否はリポジトリの公開設定とGitHubプランによる。

## 言語開発

`dictionary.json` が v0.1 の語彙と文法の参照データ。`grammar.md` はその文法・発音規則の抜粋。辞書を変更してもHTML内のデータは自動更新されないため、アプリも合わせて更新すること。

言語名は未決定。既出語と新案を区別し、互換性を壊す変更は記録する。
